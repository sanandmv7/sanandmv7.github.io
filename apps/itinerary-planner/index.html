Itinerary Planner

Back to Home

A modern, open-source Android application for planning and managing travel itineraries. Built with Kotlin and licensed under GPL v3.

Kotlin Android GPL-3.0 Open Source

Features

  • 📅 Plan Management — Create, view, and manage multiple travel itineraries
  • ⏰ Task Scheduling — Add tasks with start/end times and duration
  • 💰 Cost Tracking — Track expenses for each activity and overall trip budget

Installation

Available on F-Droid or as a direct APK download from GitHub Releases.

  • Download the latest APK from the Releases page
  • Or install via F-Droid
